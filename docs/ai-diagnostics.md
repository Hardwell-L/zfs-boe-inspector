# 规则详情、过程记录与 AI 分析

本轮扩展新增区域点选、结构化依赖详情、手动过程记录和 AI 对话。业务侧仍使用原来的 Adapter Mixin/Composable 接入；需要升级 Adapter 才能使用页面区域点选与过程记录。扩展通过 `BridgeStatus.capabilities` 判断支持情况，旧 Adapter 可继续查看已有快照和规则。

## 规则依赖和区域选择

规则诊断的依赖详情展示字段与区域名称、当前值、显示文本、来源行、取值状态及用途。显示文本优先读取 `labelCode`，其次读取配置中已有的 `options` / `optionProps`；不请求字典或数据源。

`computed` 区分本区域当前行、跨区域第 1 行和汇总引用。其他规则不能确认执行行时展示候选行，每个依赖最多 50 行，明确显示省略数量。汇总引用展示源行，不能据此声称已观察到实际汇总输入。`null`、空字符串、`0`、`false`、缺失和截断分别显示。

依赖标题右侧显示当前值摘要，多行候选值展示首行和其余行数；长值展开查看。工具栏可选择字段或区域。区域复用 `areaCode.billArea` 标识，字段点选解析 `labelCode` 为真实字段编码；点选后加入 AI 范围。AI 面板支持连续点选，点击“完成选择”或按 Esc 保留所选项并退出；30 秒无选择操作后超时退出并保留累计结果。旧 Adapter 回退为单次选择。也可在配置详情点击“加入 AI 分析范围”，或在 AI 面板选择区域、字段及行号。区域留空行号表示全部行，字段留空表示第 1 行。

## 记录一次问题

1. 在“过程记录”点击“开始新记录”。
2. 回到 BOE 页面手动操作，复现问题。
3. 点击“停止记录”，筛选字段、区域、方法或错误。
4. 展开事件检查输入、同步返回或可见异常，点击“交给 AI 分析”。

Adapter 对当前实例已存在的方法安装临时观察包装，停止或注销后恢复原属性；不会主动调用业务方法。涵盖字段更新、计算触发、校验入口及提示、关联申请转换与差旅标准入口。能力面板逐个显示方法是否存在；存在只表示入口可观察，不代表内部步骤完整。

只有同步调用栈内的嵌套调用关联 `parentId`。异步方法返回原 Promise，不额外附加处理器，避免改变宿主的 `unhandledrejection` 行为，事件保持 `pending`；`after` 是方法返回时立即采集的值，不是 Promise 完成后的最终值。后续字段更新独立记录，不推断异步因果。`returned` 也不代表校验通过。

内部函数、中间表达式、被业务代码捕获的异常和服务端步骤可能不可见。例如 `initComputeMixin` 内部捕获异常后直接返回，Adapter 无法恢复原始错误。浏览器异常是页面级补充证据，多单据并存时不能保证归属。手动粘贴错误仍可分析。

每次会话上限为 1,000 条事件或 5 MB，达到上限停止记录。事件序列化限制深度、数组长度和属性数量，单项超过 32,768 字符会标为截断。记录含开始快照；结束快照在剩余容量允许时保存。切换实例身份、组件注销或页面离开时停止。记录保存在页面内存，刷新后丢失；没有云端持久化。

## AI 设置和发送

默认 Base URL 为 `https://api.deepseek.com`、模型为 `deepseek-v4-flash`。填入 Key 即可发送；可选择 `deepseek-v4-pro` 或填写其他兼容模型名。高级设置支持使用 Chat Completions 与 SSE 的 OpenAI 兼容接口，Base URL 是接口前缀，例如 `https://example.com/v1`。HTTPS 为默认要求，本机地址允许 HTTP。连接测试会向选定模型发送一个简短测试请求，不包含单据数据。

Key 在扩展侧使用，不放入页面 Bridge、快照或报告。默认通过 `chrome.storage.session` 保留在浏览器会话中；勾选“记住本机 Key”才保存在本机扩展存储中，不使用同步存储。存储仅允许受信任扩展上下文访问；本机持久存储不是加密保险库。

发送前可查看实际消息、关联补充的配置与依赖，并逐项排除或保留原值。默认按字段名、结构化上下文和常见文本格式遮盖人员、电话、证件、账号等信息；不能保证识别所有自定义敏感字段，需检查预览。凭据类字段始终移除。脱敏不更改单据，代号在同一对话中保持一致。

字段/区域分析默认包含配置、当前值、显示文本和已采集运行态，仅补充直接相关规则及其依赖，不递归扩散。证据按所选范围、关联依赖、诊断和过程分组，可整体切换或逐项调整。配置中重复的 dataSource 内容合并并注明来源，空占位项记录在 omittedEmptyFields，损坏配置保留原文；配置映射中的 ID、NAME 等标识不作为业务值脱敏。过程中的非整单上下文只包含匹配字段的前后值；从过程面板明确选中某个事件时，该事件的完整已采集输入输出也会进入预览。整单模式可发送完整快照数据、差旅与关联申请状态。实际请求使用紧凑 JSON，格式化预览默认折叠。所有发送上限为 150 KB，按实际请求体计算；超限展示占用最大的证据，需缩小范围，不静默截断请求。

AI 默认先给简短结论、关键证据和建议步骤，可追问或请求详细分析。通过受限 Markdown 展示列表、表格、代码和引用，不执行 HTML、链接或图片。每次请求冻结证据、范围和快照时间，引用 `[E编号]` 绑定该次实际发送的脱敏内容；未知编号标明无效。AI 不修改确定性规则结果，不自动修复配置或单据。

支持多轮追问、复制回答、手动停止和失败后重新发送。仅完成的回答加入后续历史，最多最近两轮、16 KB，按整轮移除并提示。切换单据、模型、分析范围、脱敏选择或刷新快照会开启新上下文，旧回答仍可查看，不加入新请求。输出默认 4096，可在高级设置调整；达到上限保留内容并提供“继续生成”，由用户点击触发新请求。停止和异常中断也保留已有内容，发送期间固定范围。

## 协议增量

保留 Snapshot/Bridge v1 和旧字段选择方法，增加可选能力：

```typescript
startPicker(mode: 'field' | 'area', instanceId?: string, options?: { continuous?: boolean })
locateSelection(selection: InspectionSelection, instanceId?: string)
startTrace(instanceId: string)
stopTrace()
getTrace()
clearTrace()
```

`continuous-picker` 能力表示支持连续选择；可选 `PickerState.targets` 返回本次累计去重列表，在移动、退出和超时后保留。未传 continuous 时维持单选行为。`PickerState.target` 返回字段或区域选择，字段仍返回兼容的 `selection`。`TraceSession` 包含快照、事件、覆盖与缺口。诊断条目增加 `dependencyDetails`；旧的 `dependencies` 和 `currentValues` 保留，多行候选值包含行号及状态。
